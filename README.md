# grant-radar

정부지원사업 공고를 여러 출처에서 모아 검색·제공하고, 기초 수준의 사업계획서 초안 하네싱을 MCP 도구로 내보내는 수집 앞단.

## 무엇인가

(1) 국내 정부지원사업 공고를 공식 API와 크롤링으로 모아 하나의 정규화 스키마로 제공한다.

(2) 결과를 MCP(Model Context Protocol) 도구로 내보낸다. 초안 생성에 쓰는 LLM은 도구를 호출하는 에이전트 쪽이 붙이며, 이 프로젝트는 자체 LLM 키를 두지 않는다.

(3) 제공 기능은 공고 검색·상세 조회와, 공고를 입력으로 한 사업계획서 초안 프레임(PSST·평가배점 매핑·작성 프롬프트) 생성까지다. 누구나 만들 수 있는 기초 수준에 한정한다.

## 범위

(1) 한다 — 공고 수집(API 우선, 크롤링 최후), 정규화, 중복 제거, MCP 도구 노출, 기초 사업계획서 하네싱.

(2) 하지 않는다 — 집행·정산. 그 영역은 이 프로젝트 밖이다.
